🤖 Sentiment Analysis (ML.NET)

📌 Overview
This project is a **Sentiment Analysis system** developed using **C# and ML.NET**.  
It classifies text input into:
- Positive 😊  
- Negative 😡  
- Neutral 😐
- 
✨ Features
- Text-based sentiment prediction  
- Machine Learning model using ML.NET  
- GUI-based user interface  
- Real-time analysis of user input  
- Easy-to-use application

⚙️ Technologies Used
- C#  
- .NET Framework  
- ML.NET  
- Windows Forms
  
▶️ How to Run
1. Open the project in **Visual Studio**  
2. Restore NuGet packages  
3. Set the startup project  
4. Run the application
